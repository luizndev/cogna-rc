Como Personalizar Mensagens

1. Inserir Dados da Planilha com []

Use colchetes [] para puxar o valor de uma coluna por linha.

Exemplo: Olá [nome], sua compra foi registrada com o código [codigo]!

2. Fazer Cálculos com {}

Use chaves {} para fazer operações matemáticas com colunas numéricas.

Exemplo: Valor total: R$ {[valorA] + [valorB]}

Você pode usar os operadores: +, -, *, /

3. Formatação de Texto do WhatsApp

  • *texto* → texto
  • _texto_ → texto
  • ~texto~ → texto
  • `texto` → texto

Exemplo Final:

Olá *[nome]*, seu saldo atual é de R$ {[creditos] - [debito]}.
Código da transação: [codigo]
